# 🎬 Movie Ratings EDA

Exploratory Data Analysis of Movie Ratings using Python, Pandas, NumPy, Matplotlib, and Seaborn.

## 📌 About the Project

This project performs Exploratory Data Analysis (EDA) on a movie ratings dataset to discover meaningful patterns, trends, relationships, and insights hidden within the data.

The analysis covers the complete data analysis workflow, starting from loading and understanding the dataset to cleaning, analyzing, visualizing, and interpreting the data.

## 🎯 Objectives

The main objectives of this project are:

- Understand the structure of the movie ratings dataset
- Explore the distribution of movie ratings
- Analyze movie-related patterns and trends
- Identify relationships between different variables
- Detect missing values and potential outliers
- Use statistical analysis to understand the data
- Create meaningful visualizations
- Extract useful insights from the dataset

## 🧠 Exploratory Data Analysis Workflow

The project follows the following workflow:

1. Data Loading
2. Data Inspection
3. Data Cleaning
4. Handling Missing Values
5. Statistical Analysis
6. Univariate Analysis
7. Bivariate Analysis
8. Multivariate Analysis
9. Data Visualization
10. Insight Generation

## 🚀 Getting Started

### Clone the Repository

    git clone https://github.com/InfinitePraveen/Movie-Ratings-EDA.git

### Navigate to the Project Directory

    cd Movie-Ratings-EDA

### Install Required Libraries

    pip install pandas numpy matplotlib seaborn jupyter

### Run the Jupyter Notebook

    jupyter notebook

Open the `Movie Ratings EDA.ipynb` notebook and execute the cells sequentially.

## 🔍 EDA Process

### 1. Data Loading

The dataset is loaded into a Pandas DataFrame for analysis.

### 2. Data Inspection

The dataset is inspected to understand:

- Number of rows and columns
- Column names
- Data types
- Missing values
- Duplicate records
- Basic statistical properties

### 3. Data Cleaning

The data is examined and prepared for analysis by identifying missing values, checking duplicates, correcting data types, and handling inconsistencies where required.

### 4. Statistical Analysis

Descriptive statistics are used to understand the central tendency, spread, distribution, and general characteristics of the movie ratings data.

### 5. Data Visualization

Different visualization techniques are used to identify patterns and relationships that may not be immediately visible from the raw data.

### 6. Insight Generation

The final stage of the analysis focuses on extracting meaningful insights and observations from the data.
